# Age Detection Model

Detects **age range** and **gender** from images or live webcam feed using OpenCV's pre-trained Caffe deep learning models. Supports single image, batch folder processing, and live webcam.

## Setup

```bash
pip install -r requirements.txt
```

## Run

**Single image:**
```bash
python age_detection.py --image photo.jpg
```

**Batch — process entire folder of images:**
```bash
python age_detection.py --batch sample_images/
```

**Live webcam:**
```bash
python age_detection.py --webcam
```

## Quick Test (No Photos Needed)

Generate synthetic sample images and run batch detection on them:
```bash
python generate_sample_images.py
python age_detection.py --batch sample_images/
```

## How It Works

1. Model weights auto-download on first run into `models/` (~30 MB total)
2. Face detection using OpenCV DNN + ResNet SSD
3. Age prediction — classifies into 8 buckets: `(0-2) (4-6) (8-12) (15-20) (25-32) (38-43) (48-53) (60-100)`
4. Gender prediction — Male / Female
5. Results saved to `output.csv` and annotated images saved to `batch_output/`

## Output Files

| File | Description |
|------|-------------|
| `output.csv` | Detection results for all processed images |
| `sample_output.csv` | Preview of expected results |
| `batch_output/` | Annotated images from batch processing |
